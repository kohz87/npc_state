# v0.2 legacy runtime

The root v0.2 JavaScript modules and historical tests remain in the repository as rollback/reference material during the v0.3 rewrite.

They are **not loaded** by the v0.3 bootstrap and are **not release-gating tests** for v0.3.

The only supported v0.2 compatibility path in the v0.3 runtime is the read-only sidecar importer in `v03/migrate-v02.js`.
