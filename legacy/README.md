# Legacy NPC State

The supported extension line is v0.3.x at the repository root.

`legacy/v0.2.x/` is an exact frozen snapshot of NPC State v0.2.23 at commit `e8baa95d081c58e91046379eb7d14853480c2940`. It preserves the old runtime, tests, reports, documentation, manifest, and release history for debugging, recovery, and archaeology.

Nothing in this directory is loaded by the root v0.3 `manifest.json` or `bootstrap.js`. Do not develop new features here. Fixes and new work belong to the v0.3 runtime.
